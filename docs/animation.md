# 4DGS 动画预览与编辑

## 启动与导入

需要支持 WebGPU 的浏览器和 Node.js 20.19 或更新版本：

```bash
npm ci
npm run build
npm run serve
```

BGS 0.1 可通过拖入资产目录、选择同一文件夹下的 `scene.json`（解析其引用的
ply/bin）、同时选择清单及其引用文件、拖入包含资产的 ZIP，或导入 `scene.json`
URL 加载。只选 `scene.json` 时，若浏览器允许，会再请你选择该文件夹。URL
资源相对于清单解析；服务器必须允许浏览器读取所有引用文件。目录内的路径
不能越出资产范围。
本机真实样例是 `/data/zhuyutian/data/bgs/samples/pick-the-block-20261004/`，
不包含在 Git 仓库中。

## 播放与查看绑定

导入后底部显示动画面板与时间轴。选择图层及片段，使用播放、暂停、逐帧
和循环控件；时间字段以秒计。播放倍率独立于时间轴帧率。短片段在多个
图层共同播放时保持末帧；已有相机关键帧不会因为新动画导入而被截断。

“绑定姿态”显示基础姿态，不代表片段的第一个样本。样本帧和来源帧显示
在面板中；来源帧是资产记录的采集帧，不受编辑器时间轴帧率影响。

节点颜色按钮只改变预览。取合并重复节点权重后的最大权重节点，同权重
取较小节点索引；静态根使用中性色。展开“绑定详情”查看图例与资产坐标轴。
仅选择一个高斯时显示稳定 ID 及原始四槽权重，包括零权重槽。选择、锁定
反馈保留；Overdraw 显示热图，退出后恢复节点染色。原始 SH 与导出颜色
不受绑定染色影响。

选择和编辑操作会暂停播放，并固定操作姿态。工具结果写回每个实例的
基础姿态编辑，因此继续播放时高斯仍随原节点运动。移动、旋转、非均匀
缩放及其组合保留完整协方差；撤销与重做使用操作时记录的实例状态。
复制图层共享不可变资源，拥有独立播放与编辑状态。分离、删除、恢复及
项目重载保留对应实例的绑定。

## 保存与导出

- **项目 `ssproj`**：保存动画资产、图层摆放、共享资源、实例编辑、播放
  设置和预览状态。版本 2 继续读取旧版本 0/1 静态项目。
- **静态格式**：PLY、压缩 PLY、SPLAT、SPZ、SOG 导出当前时间的静态快照。
  不携带后续动画。截图使用当前完整姿态；视频逐帧等待指定时间的完整求值。
- **标准 BGS**：选中一个动画图层后导出 `.bgs.zip`。写入基础姿态中的
  几何及颜色编辑、保留实例、原始四槽绑定、全部片段和未知 PLY 属性。
  生成新资产 ID、SHA-256 清单及对实际输出执行的验证记录。

BGS 采用原始米制、Z-up 资产坐标；编辑器的图层摆放由 `ssproj` 保存。
显示变换为 `(x, y, z) -> (-y, z, -x)`，不再次应用来源 `normalization`。
动画节点及基础姿态编辑不旋转 scene-frame SH。

标准 BGS 无法表达的图层摆放烘焙会被明确拒绝。静态 SH 快照也拒绝含
非均匀缩放或剪切的整体图层变换；这与允许逐实例基础姿态仿射编辑不同。
奇异 BGS 协方差不能导出，不会自动近似或静默忽略。完整保存优先使用项目。

## 扩展接口

`src/animation/types.ts` 将不可变 `AnimationAsset`、逐图层
`AnimationInstance`、异步可取消的 `DeformationProvider` 和带版本的
`EvaluatedFrame` 分开。时间单位统一为秒，能力声明区分固定拓扑、绑定与
编辑逆映射。BGS 是首个实现；本次不加载神经网络或支持动态拓扑。

GPU 仿射矩阵图集是当前渲染适配层：渲染、排序、拾取、选择、数据查询
和包围盒共享当前提交的姿态。包围盒在 GPU 归约，只回读归约结果。
快速拖动合并请求；捕获等待精确时间；加载失败保留最后有效姿态并报错。

设 `W` 为图层变换、`D_i(t)` 为变形、`C_i` 为基础姿态编辑，则
`world_i = W * D_i(t) * C_i * bind_i`。冻结姿态中的图层空间编辑 `U`
更新为 `C_i' = inverse(D_i) * U * D_i * C_i`。逐实例编辑使用独立的
双精度仿射存储，不占用静态图层的 16 位变换调色板。
